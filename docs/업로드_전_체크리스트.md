# 업로드 전 체크리스트

이 문서는 브랜치 생성과 GitHub 업로드를 직접 진행할 때 사용합니다.

```powershell
git lfs install
git switch -c <브랜치명>
git status --short
git add .gitattributes
git add .
git lfs ls-files
git diff --cached --check
git diff --cached --stat
```

확인 항목:

- ONNX 3개가 `git lfs ls-files`에 표시되는지 확인
- `.env`, 로컬 DB, 가상환경, 빌드 결과가 staged 목록에 없는지 확인
- `.env.example`의 키가 비어 있고 주소가 `YOUR_SERVER_IP`인지 확인
- 변경 내용을 검토한 뒤 직접 커밋·푸시하고 Pull Request 생성

현재 저장소에 포함할 ONNX 파일:

- `assets/models/weapon_detector_finetuned.onnx`
- `backend/ai/models/guardian_context_model/model.int8.onnx`
- `backend/ai/models/yamnet/yamnet.onnx`
