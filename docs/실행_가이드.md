# 로컬 실행 가이드

아래 명령은 저장소 루트 `C:\Users\JinYoung\Desktop\POLAPP`을 기준으로 합니다. 휴대폰과 노트북을 같은 네트워크에 연결하고 `YOUR_SERVER_IP`를 노트북의 현재 IPv4 주소로 바꾸세요.

## 1. 로컬 연동 백엔드

```powershell
cd backend\admin-local
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\start_backend.ps1
```

공유 환경에서는 `.env`의 `JWT_SECRET`과 `SESSION_SECRET`에 서로 다른 긴 임의 문자열을 지정하세요.

테스트 계정:

| 구분 | ID | 매칭 코드 |
|---|---|---|
| 관리자 | `ADMIN-001` | `13579` |
| 현장 경찰관 | `P-1001` | `11111` |
| 현장 경찰관 | `P-1002` | `22222` |

## 2. AI 서버

```powershell
cd backend\ai
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\start_ai.ps1
```

LLM을 쓰려면 `.env`에서 공급자를 선택하고 해당 키만 입력합니다. 키가 없으면 법률 질의와 보고서 초안은 외부 API를 호출하지 않는 대체 경로로 동작합니다. 첫 실행의 Whisper 모델 준비에는 시간이 걸릴 수 있습니다.

## 3. 현장 앱

```powershell
flutter pub get
flutter run `
  --dart-define=NAVER_MAP_CLIENT_ID=YOUR_MOBILE_MAP_CLIENT_ID `
  --dart-define=API_SERVER_URL=http://YOUR_SERVER_IP:4440 `
  --dart-define=WS_SERVER_URL=http://YOUR_SERVER_IP:4440 `
  --dart-define=AI_SERVER_URL=http://YOUR_SERVER_IP:8765
```

AI 서버에 `AI_SERVER_TOKEN`을 설정했다면 같은 값을 앱 실행 시 `--dart-define=AI_SERVER_TOKEN=...`으로 추가합니다.

## 4. 관리자 웹

```powershell
flutter run -d web-server `
  --web-hostname 0.0.0.0 `
  --web-port 8080 `
  --dart-define=NAVER_MAP_WEB_CLIENT_ID=YOUR_WEB_MAP_CLIENT_ID `
  --dart-define=API_SERVER_URL=http://127.0.0.1:4440 `
  --dart-define=WS_SERVER_URL=http://127.0.0.1:4440
```

브라우저에서 `http://localhost:8080`을 열고 관리자 계정으로 로그인합니다.

## 확인 주소

- 연동 백엔드: `http://localhost:4440/health`
- AI 서버: `http://localhost:8765/health`
- 관리자 웹: `http://localhost:8080`
