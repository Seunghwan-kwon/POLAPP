# 로컬 실행 가이드

명령은 저장소 루트에서 시작합니다. 휴대폰과 노트북은 같은 네트워크에 연결하고 `YOUR_SERVER_IP`를 노트북의 현재 IPv4 주소로 바꿉니다.

## 준비 항목

- Flutter SDK와 Android 개발 환경
- Node.js와 npm
- Python 3.12
- 팀 백엔드와 호환되는 MySQL 스키마 및 테스트 계정
- 모바일용 및 웹용 네이버 지도 Client ID

법률 질의와 보고서 정리에 LLM을 사용할 때만 Gemini 또는 OpenAI API 키가 필요합니다. ChatGPT 구독과 OpenAI API 사용료는 별도입니다.

## 1. Node.js 백엔드

`backend/.env.example`을 복사하고 팀 개발 DB 정보를 입력합니다. `sessionSecret`과 `jwtSecret`은 서로 다른 긴 임의 문자열을 사용합니다.

```powershell
cd backend
npm install
Copy-Item .env.example .env.local
npm run local
```

기본 예시의 `portPrefix=4360`은 서버 포트 `4440`을 의미합니다. 위험 알림을 포함한 전체 연동 테스트 전에는 `backend/src/ai-integration.sql`을 DB에 적용해야 합니다. 소스를 수정한 경우 TypeScript 컴파일러가 준비된 환경에서 `npm run build` 후 실행합니다.

팀의 원격 백엔드를 사용할 때는 로컬 Node.js 서버를 켜지 않고 앱과 관리자 웹의 `API_SERVER_URL`, `WS_SERVER_URL`을 원격 주소로 지정합니다. 단, 원격 서버에 이 문서의 AI 연동 모듈이 아직 반영되지 않았다면 기존 기능만 동작하고 위험 알림과 카메라 관제는 동작하지 않습니다.

## 2. AI 서버

```powershell
cd backend\ai
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\start_ai.ps1
```

`backend/ai/.env`에서 사용할 LLM 공급자와 해당 키를 설정합니다. 키가 없으면 법률 질의와 보고서 초안은 외부 API를 호출하지 않는 대체 경로로 동작합니다. `AI_SERVER_TOKEN`을 설정하면 앱에도 같은 값을 전달해야 합니다.

## 3. 현장 앱

```powershell
flutter pub get
flutter run `
  --dart-define=NAVER_MAP_CLIENT_ID=YOUR_MOBILE_MAP_CLIENT_ID `
  --dart-define=API_SERVER_URL=http://YOUR_SERVER_IP:4440 `
  --dart-define=WS_SERVER_URL=http://YOUR_SERVER_IP:4440 `
  --dart-define=AI_SERVER_URL=http://YOUR_SERVER_IP:8765 `
  --dart-define=AI_SERVER_TOKEN=YOUR_OPTIONAL_TOKEN
```

## 4. 관리자 웹

```powershell
flutter run -d web-server `
  --web-hostname 0.0.0.0 `
  --web-port 8080 `
  --dart-define=NAVER_MAP_WEB_CLIENT_ID=YOUR_WEB_MAP_CLIENT_ID `
  --dart-define=API_SERVER_URL=http://127.0.0.1:4440 `
  --dart-define=WS_SERVER_URL=http://127.0.0.1:4440
```

브라우저에서 `http://localhost:8080`을 열고 팀 DB의 관리자 계정으로 로그인합니다.

## 5. 빠른 확인

```powershell
Invoke-RestMethod http://localhost:4440/health
Invoke-RestMethod http://localhost:8765/health
node backend/test/ai-integration.test.js
flutter analyze
```

전체 로컬 연동은 Node.js 백엔드가 접근할 수 있는 팀 MySQL 스키마와 테스트 계정이 있어야 확인할 수 있습니다. DB 접속 정보가 없더라도 AI 서버 테스트, Node.js AI 입력 단위 테스트, Flutter 정적 분석은 독립적으로 수행할 수 있습니다.
