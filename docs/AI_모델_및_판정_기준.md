# AI 모델과 판정 기준

## 위험 인식

AI 서버는 하나의 값만으로 위험을 확정하지 않고 다섯 근거를 결합합니다.

| 신호 | 의미 | 산출 방식 |
|---|---|---|
| E | 음성 흥분도 | 현재 음량·활성도를 세션의 평상시 기준과 비교 |
| K | 위협 발화 | 욕설·협박·흉기·폭행 규칙과 문맥 모델 점수 중 강한 근거 사용 |
| C | 군중 소음 | YAMNet의 군중·다중 화자 관련 클래스 점수 |
| S | 위험 음향 | 비명·충돌·파손 등 선택 클래스 점수 |
| T | 시간 추세 | 최근 30초의 반복, 같은 유형 재발, 신호 상승 폭 |

Level 4는 흉기·폭행 같은 중대 발화에 다른 강한 신호가 동반되거나 위험 음향·반복이 매우 높은 경우, Level 3은 강한 위협 발화나 여러 근거가 동시에 확인되는 경우, Level 2는 단일 주의 신호가 확인되는 경우로 정합니다. 그 외는 Level 1입니다. 정확한 임계값은 `backend/ai/data/risk_policy.json`과 `backend/ai/src/risk_engine.py`에서 관리합니다.

화면의 근거 지수는 가장 강한 신호에 제한된 보조 가중치를 더한 0~100 진단값이며 폭력 발생 확률이 아닙니다.

## 사용 모델

| 기능 | 모델·데이터 | 현재 적용 |
|---|---|---|
| STT | faster-whisper small | 16 kHz 음성 전사, 반복·무음 환각 억제 |
| 발화 문맥 | KLUE/RoBERTa-small + KCDD | INT8 ONNX, KCDD 공식 분할 3개 시드 Macro-F1 평균 0.8724 |
| 위험 음향 | Google YAMNet + AudioSet | 521개 클래스 중 현장 위험 관련 점수만 보조 근거로 사용 |
| 흉기 객체 | SSDLite320-MobileNetV3-Large + Open Images V7 Bottle/Knife | 모바일 ONNX 추론, 클래스별 임계값 적용 |

KCDD는 온라인 대화 자료이고 Open Images는 실제 국내 현장 영상이 아니므로, 위 수치를 현장 성능으로 해석하면 안 됩니다. 실사용 전에는 동의받은 국내 현장 유사 음성·영상으로 오탐률, 미탐률, 사건별 재현율과 시간당 오경보를 별도로 검증해야 합니다.

## 보고서와 법률 기능

- 보고서: 긴 녹음을 30초 구간과 1.2초 중첩으로 처리하고, 중첩 문장 제거 후 사건 유형·신고 내용·현장 확인·조치·추가 확인 항목을 구성함
- 법률: 로컬 법령 색인을 먼저 검색하고 질문과 직접 관련된 근거를 LLM에 제공함. 키가 없으면 검색 결과 기반 대체 답변을 사용함
- 두 기능 모두 결과를 확정 문서나 법률 판단으로 취급하지 않고 사용자 검토를 요구함
