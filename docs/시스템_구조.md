# 시스템 구조

## 실행 구성

| 구성 요소 | 위치 | 기본 포트 | 역할 |
|---|---|---:|---|
| 현장 경찰관 앱 | 저장소 루트 Flutter 앱 | - | 위치·메시지·AI 기능·카메라 입력 |
| 관리자 관제 웹 | 저장소 루트 Flutter 웹 빌드 | 8080 | 위치 관제·위험 알림·카메라 확인 |
| AI 서버 | `backend/ai` | 8765 | STT·위험 분석·법률 질의·보고서 초안 |
| 로컬 연동 백엔드 | `backend/admin-local` | 4440 | 로그인·위치·메시지·신고·위험 알림 중계 |

## 주요 흐름

1. 앱이 약 8초 단위 음성을 연속 수집해 AI 서버로 전송함.
2. AI 서버가 STT 결과, 발화 규칙, 문맥 분류, 음향 사건, 현장 기준 음량과 최근 추세를 결합해 Level 1~4를 반환함.
3. 앱은 결과와 대응 가이드를 표시하고 Level 3·4 또는 카메라의 칼 감지 이벤트를 연동 백엔드에 전송함.
4. 연동 백엔드는 `eventId`로 중복을 막고 관리자 방에 `threatDetected` 이벤트를 전달함.
5. 관리자 웹은 최신 알림, 위치, 근거, 위험도 변화와 사건별 기록을 표시함.
6. 카메라 미리보기는 기기에서 계속 표시하고 ONNX 추론은 약 1.1초 간격으로 수행함. 관제용 JPEG는 최신 프레임만 메모리에 보관함.

## AI 구성

- STT: `faster-whisper` small, 한국어 전사 프로필과 환각·반복 억제 후처리 적용
- 발화 문맥: `KLUE/RoBERTa-small` 기반 KCDD 파인튜닝 모델의 INT8 ONNX
- 위험 음향: AudioSet 521개 클래스로 사전학습된 YAMNet ONNX의 선택 클래스 점수
- 흉기 탐지: SSDLite320-MobileNetV3-Large 기반 bottle/knife 파인튜닝 ONNX
- 법률 질의: 국가법령정보 색인 검색 후 선택한 LLM 또는 규칙 기반 대체 답변
- 보고서 초안: 장음성 분할 STT, 중복 제거, 필드 추출, 완전성 검사, 선택적 LLM 정리

위험도 계산과 모델 한계는 [AI 모델 문서](AI_모델_및_판정_기준.md)에 별도로 정리되어 있습니다.
