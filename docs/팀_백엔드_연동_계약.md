# 팀 백엔드 연동 계약

`backend/admin-local`은 AI 기능을 팀 백엔드와 독립적으로 검증하기 위한 로컬 기준 구현입니다. 팀원이 작성한 실제 백엔드의 기존 구조를 교체하지 않고, 아래 계약 중 위험 알림과 카메라 항목만 같은 의미로 반영하는 것이 목표입니다.

## 인증

- `POST /login`: `officerId`, `matchingCode`를 검증하고 JWT, 역할, 이름, 계급, 관할을 반환함
- 모바일 REST 요청: `Authorization: Bearer <token>` 사용
- 관리자 웹: 세션 쿠키와 JWT 응답을 함께 지원함
- 실제 배포에서는 Socket.IO 연결도 로그인 토큰으로 인증하고, 관리자 이벤트는 `ADMIN` 역할에만 전달해야 함

## REST 계약

| 메서드·경로 | 권한 | 용도 |
|---|---|---|
| `GET /health` | 공개 | 서버 상태 확인 |
| `GET /reports` | 로그인 | 신고 목록 조회 |
| `POST /reports` | 관리자 | 신고 생성 |
| `PATCH /reports/{id}/close` | 관리자 | 신고 종결 |
| `POST /threat-alerts` | 현장 경찰관 | AI·카메라 위험 이벤트 등록 |
| `GET /threat-alerts?limit=50` | 관리자 | 위험 기록 조회 |
| `POST /camera-stream/status` | 현장 경찰관 | 카메라 세션 시작·종료 |
| `POST /camera-stream/frame` | 현장 경찰관 | 최신 JPEG와 탐지 결과 전송 |
| `GET /camera-streams` | 관리자 | 활성 카메라 목록 조회 |
| `GET /camera-streams/{officerId}/frame` | 관리자 | 최신 카메라 프레임 조회 |

### 위험 알림 필수 필드

```json
{
  "eventId": "클라이언트에서 생성한 전역 고유값",
  "sessionId": "하나의 위협 인식 실행 단위",
  "category": "weapon",
  "alertLabel": "흉기",
  "riskLevel": 3,
  "evidenceIndex": 88.0,
  "reasons": ["카메라에서 칼 감지"],
  "latitude": 37.0,
  "longitude": 127.0,
  "occurredAt": "ISO-8601 UTC"
}
```

`eventId`에는 UNIQUE 제약을 두어 네트워크 재전송이 중복 알림으로 저장되지 않게 해야 합니다. Level 1·2의 저장 정책은 운영 기준에 맞추되, 관제 실시간 팝업은 Level 3·4를 대상으로 합니다. 카메라의 칼 탐지는 음성 유무와 관계없이 Level 3 이벤트를 생성합니다.

## Socket.IO 계약

클라이언트 전송 이벤트:

- `join`: 로그인 사용자 방 입장
- `sendMyLocation`: 현장 좌표 갱신
- `sendRadioMessage`: 관할 메시지 전파

서버 전송 이벤트:

- `updateColleagueLocation`, `removeColleagueLocation`
- `receiveRadioMessage`
- `reportCreated`, `reportClosed`
- `threatDetected`
- `cameraStreamUpdated`, `cameraStreamStopped`

## 저장 정책

- `threat_alerts`에는 사건·경찰관·위험 단계·근거·좌표·시간을 저장함
- 원본 음성, STT 전문과 카메라 프레임은 기본 저장 대상에서 제외함
- 카메라 프레임은 최신 1장만 메모리에 유지하고 8초 동안 갱신이 없으면 제거함
- 운영 저장이 필요할 경우 보존 기간, 접근 권한, 암호화, 감사 로그와 정보주체 동의 기준을 먼저 확정해야 함

## 실제 백엔드 반영 순서

1. 기존 사용자·세션·관할 모델에 `threat_alerts` 스키마만 추가함.
2. `POST/GET /threat-alerts`와 `threatDetected` 이벤트를 기존 인증·권한 구조로 구현함.
3. 관제 카메라가 필요하면 최신 프레임 중계 API를 별도 모듈로 추가함.
4. 앱의 `API_SERVER_URL`, `WS_SERVER_URL`을 팀 개발 서버로 바꿔 계약 테스트를 수행함.
5. 재전송 중복, 관리자 권한, CORS, 끊김 후 재접속과 이벤트 순서를 검증함.

참고 구현은 `backend/admin-local/app.py`, 저장 구조는 `backend/admin-local/database.py`, 앱 송신 코드는 `lib/services/threat_alert_service.dart`와 `lib/services/camera_stream_service.dart`에 있습니다.
